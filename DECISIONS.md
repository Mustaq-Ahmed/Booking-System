# Architecture Decisions

## ADR-001 - MongoDB as Primary Database

Decision:
MongoDB is the primary database.

Reason:
The primary learning objective is deep MongoDB mastery.

---

## ADR-002 - PostgreSQL Excluded

Decision:
PostgreSQL and Prisma are not part of the main project.

Reason:
They would dilute the primary learning objective.

---

## ADR-003 - React Used Primarily for Backend Testing

Decision:
Frontend design is not a primary project objective.

Reason:
The backend is the main learning focus.

---

## ADR-004 - Avoid Premature Microservices

Decision:
Start with a modular monolith.

Reason:
We want to understand service boundaries before distributing them.

## ADR-005 — Learning Depth Over Timeline

Decision:
The project will not compromise learning depth to meet a
four-month resume milestone.

Reason:
The primary objective is to develop independent backend
engineering ability, not merely complete a portfolio project.

The project may become resume-worthy during the journey,
but resume readiness is a consequence of demonstrated
understanding and implementation quality.
